2. Allgemeines

TheCrazyBot („der Bot") ist ein Discord-Bot, der auf Discord-Servern („Guilds") installiert werden kann, auf denen Server-Administratoren ihn hinzufügen. Diese Datenschutzerklärung informiert darüber, welche Daten der Bot im Rahmen seines Betriebs verarbeitet, zu welchem Zweck, auf welcher Rechtsgrundlage und wie lange.

Der Bot verarbeitet ausschließlich Daten, die über die Discord-API bereitgestellt werden, sowie Daten, die durch die Nutzung der Bot-Funktionen entstehen (z. B. Level-Punkte, Ticket-Nachrichten). Discord selbst verarbeitet als eigener Verantwortlicher zusätzlich Daten gemäß der Datenschutzrichtlinie von Discord — diese Erklärung betrifft ausschließlich die Verarbeitung durch TheCrazyBot.

4. Speicherdauer

  • Nutzerprofile (Level, Economy, Statistiken): solange du auf mindestens einem Server aktiv bist, auf dem der Bot läuft, bzw. bis du sie über /privacy delete-my-data selbst löschst.
  • Ticket-Transkripte: verschlüsselt gespeichert, solange der Server den Bot nutzt bzw. bis der Owner sie über /privacy delete-server-data löscht oder der Bot entfernt wird.
  • Moderations-Log-Inhalte: nicht dauerhaft gespeichert, nur zur Anzeige im Log-Kanal des jeweiligen Servers verarbeitet.
  • Server-Daten: werden vollständig gelöscht, sobald der Bot vom Server entfernt wird, oder auf Wunsch des Owners.

Wie du diese Rechte ausübst

Für Auskunft, Export und Löschung deiner eigenen Daten musst du uns nicht extra kontaktieren:

Befehl Wirkung
/privacy view-my-data Übersicht deiner Daten in Discord, plus vollständige Kopie als JSON-Datei
/privacy delete-my-data Löscht dein gesamtes Nutzerprofil unwiderruflich (Bestätigung per Button)

Server-Owner erhalten zusätzlich über /privacy view-server-data bzw. /privacy delete-server-data eine Übersicht bzw. vollständige Löschung aller zu ihrem Server gehörenden Bot-Daten.

Für alle anderen Anliegen (Berichtigung, Einschränkung, Widerspruch, allgemeine Fragen) erreichst du uns über die in Abschnitt 1 genannten Kontaktdaten.

8. Datensicherheit

Ticket-Nachrichteninhalte werden verschlüsselt in der Datenbank gespeichert (AES-Verschlüsselung). Der Zugriff auf die Datenbank ist auf den Bot-Betrieb beschränkt. Trotz aller Sicherheitsmaßnahmen kann eine vollständige Sicherheit bei der Datenübertragung über das Internet nicht garantiert werden.

9. Automatisierte Entscheidungsfindung / Profiling

Es findet keine automatisierte Entscheidungsfindung oder ein Profiling im Sinne von Art. 22 DSGVO statt, das rechtliche Wirkung entfaltet oder dich erheblich beeinträchtigt. Level-, Economy- und Statistikwerte dienen ausschließlich Unterhaltungszwecken innerhalb des Servers.
